# Week3 - Car Class

A Java console program that models a car using object-oriented programming.

## Features
- `Car` class with plate number, model, mileage, fuel level and tank capacity
- `drive(km)`: drives the given distance if there is enough fuel (uses 0.1 liters per km)
- `refuel(amount)`: adds fuel and discards the extra if the tank is full
- `checkStatus()`: prints mileage and fuel level, and warns when fuel is below 10% of the tank
- `Week3` main class creates three cars and tests different scenarios
